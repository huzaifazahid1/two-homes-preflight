# UI design system

Part of the Two Homes Preflight spec. Source sections: P.9 (routes are in product.md A.8). Read `CLAUDE.md` first; it maps section letters to files.

# P.9 Design system, animation and UI quality

- Mobile (< 1024 px): bottom tab bar (Home, Expenses, + New raised centre, Money, More), 64 px plus safe-area inset; top bar with title and one action; bottom sheets instead of centred modals; full-screen single-column forms with sticky primary button; inputs at 16 px; `inputmode="decimal"` for amounts; touch targets >= 44 px; card lists instead of grids.
- Desktop (>= 1024 px): collapsible 248 px sidebar; content max 1200 px (ledger full width); master-detail on expenses at >= 1280 px; centred dialogs; shortcuts `N` new expense, `/` search, `Esc` close.
- Signature components: `ClauseCard` (verbatim quote in Source Serif 4 on highlighter background `clause-bg`, page chip opening the source sheet), `VerdictBadge` (icon + words + colour, never colour alone), money in Geist Mono tabular figures, `SplitBar`, `Timeline` from `events`.
- Light tokens: `bg #F7F6F2`, `surface #FFFFFF`, `surface-2 #EFEDE7`, `border #E2DED5`, `text #15201E`, `text-muted #5B6663`, `primary #12403C`, `primary-hover #0C2F2C`, `primary-soft #E3EEEC`, `accent #B4502B`, `clause-bg #FCEFC7`.
- Light status (text / background): eligible + settled `#17744A / #E4F4EA`; needs approval + due soon `#9A5B00 / #FDF1DC`; missing evidence `#6E3FB8 / #F0EAFB`; not covered + waived `#5F6670 / #EEEFF1`; late + overdue + failed + declined `#B42D27 / #FBE7E5`; needs review + processing `#2560AD / #E5EEFA`.
- Dark tokens: `bg #0F1513`, `surface #161E1C`, `surface-2 #1E2826`, `border #2A3532`, `text #E8ECEA`, `text-muted #9AA6A2`, `primary #5FC2B4` (dark text on it), clause `#F3E9C8` on `#3A3220`. Dark status: eligible `#5DD39A / #16241D`, approval `#F2B65C / #2A2112`, evidence `#B99AF0 / #221B30`, not covered `#A3AAB3 / #1E2226`, late `#F28B84 / #2E1A19`, review `#86B4F0 / #17222F`. All pairs were checked for WCAG AA contrast.
- Type: Geist Sans (UI), Geist Mono (amounts, ids), Source Serif 4 (agreement quotes only). Sizes: display 40/44 600 (landing only), H1 28/34 600, H2 22/28 600, H3 18/24 600, body 15/24 400, small 13/20, label 12/16 500, big amount 32/36 mono 500, table amount 14/20 mono, quote 16/26 serif.
- Radius 10 px cards, 8 px inputs/buttons. Motion 150 to 300 ms, disabled under `prefers-reduced-motion` (Motion's `useReducedMotion`).
- Animation (with `motion`, purposeful, never decorative noise): verdict badge animates in when the preflight result changes; clause card highlight sweeps once when it appears; bottom sheets and dialogs spring in; list items fade/slide on enter and reorder with `layout`; status chips cross-fade on real-time updates; dashboard totals count up on first load; a short success check animation on Approved and Settled; tab bar indicator slides; skeletons while loading. No parallax, no animated backgrounds, nothing over 400 ms. Theme follows system with a toggle; light is the default for screenshots and video.
- Not PayPal's blue/yellow anywhere except PayPal's own buttons.
- Skills in `.claude/skills`: use `frontend-design` when designing new screens, `vercel-react-best-practices` when writing React/Next.js code, and `web-design-guidelines` to review UI at the end of each phase. For motion: `two-homes-motion` (project rules, always loaded first for any animation work), `animate` (single animations), `choreograph` (staggered lists, sequences, cross-fades) and `review-animations` (end-of-phase motion review). These tokens and components win over any generic suggestion.
